# 合成牢大

合成大西瓜玩法的网页小游戏：前 9 级都是同一张牢大头像，第 10 级合成后变成直升机牢大。

**在线玩：** https://moshujiqiao39.github.io/hecheng-laoda/

仓库：https://github.com/moshujiqiao39/hecheng-laoda

## 怎么玩

- 左右移动瞄准，点击画布或按空格放下
- 两个相同等级碰到一起，会合成更大一级
- 堆过红色危险线并停留，就会结束
- 也可以直接打开本地的 `index.html`

## 本地运行

```bash
python -m http.server 4173
```

然后打开 http://127.0.0.1:4173
